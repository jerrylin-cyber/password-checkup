# 密碼健檢

一個不保存資料的密碼安全檢查工具。所有檢查都在瀏覽器本機完成，密碼不會傳送到伺服器。

## 線上使用

[開啟密碼健檢](https://password-checkup-tw.lazyjerry.chatgpt.site)

## 功能

- 即時顯示密碼安全強度
- 檢查密碼是否為常見高風險密碼
- 最少字元數可調整為 6–20 個字元，預設為 8 個字元
- 可個別啟用或停用下列規則：
  - 大寫英文字母
  - 小寫英文字母
  - 數字
  - 特殊符號
  - 常見密碼檢查
- 支援顯示或隱藏密碼
- 支援桌面與行動裝置版面

## 隱私

- 不會將密碼傳送到伺服器
- 不使用資料庫保存輸入內容
- 不使用瀏覽器儲存空間保存密碼
- 不含使用者行為追蹤程式碼
- 關閉或重新整理頁面後，輸入內容即消失

> 本工具只能協助檢查基本密碼規則，不能保證密碼絕對安全。建議為不同服務使用不同密碼，並搭配密碼管理工具及多重要素驗證（MFA）。

## 本機開發

### 環境需求

- Node.js `22.13.0` 以上版本
- npm

### 啟動開發環境

```bash
npm install
npm run dev
```

開發伺服器啟動後，使用瀏覽器開啟終端機顯示的本機網址。

### 建置正式版本

```bash
npm run build
```

## 常用指令

- `npm run dev`：啟動本機開發伺服器
- `npm run build`：建立正式版本
- `npm test`：執行測試
- `npm run lint`：檢查程式碼格式與規則

## 技術架構

- React
- TypeScript
- vinext
- Vite
- Cloudflare Workers 相容建置格式

## 專案結構

- `app/page.tsx`：密碼檢查功能與頁面內容
- `app/globals.css`：全站視覺樣式及響應式版面
- `app/layout.tsx`：網站中繼資料與共用版面
- `public/`：網站圖示與靜態檔案
- `.openai/hosting.json`：網站託管設定
